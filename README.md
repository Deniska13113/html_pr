# Чтобы изменить фотографию нужно
- Скачать фото
- Скопировать фото в папку с index.file (zopa -> html_pr -> site_80 -> site)
- В index.html изменить код (добавить название фото)

# Чтобы добавить к себе изменения в ветке
```
git pull
```
# Чтобы залить свои изменения на гитхаб
## Если не сделала комит !!!
```
git add .
```
```
git commit -m "message"
```
```
git push
```
## Если уже сделала комит !!!
```
git push
```
