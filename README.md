# Тебе, если вдруг хочется поиграться!

## Чтобы установать себе на компютер репозиторий

- в консоль вставляешь
```
git clone git@github.com:Deniska13113/html_pr.git
```
- потом запускаешь vs code и открываешь папку html_pr
- там окрываешь папку site_80 site и открываешь index.html
- меняешь все что тебе хочется

## Что бы залить изменения на github нужно зайти в консоль
- В консоль вставляешь 
```
cd html_pr
```
- Проверяешь что ты на правильной ветке
```
git checkout elfeat
```
-Делаешь коммит (сохранение) В КАВЫЧКАХ НАДО НАПИСАТЬ СООБЩЕНИЕ!!!
```
git commit -am ""
```
- Пушишь изменения на github
```
git push origin elfeat
```
- После этого пишешь мне, я проверю чтоты сделала и, если все хорошо, смержу в main
